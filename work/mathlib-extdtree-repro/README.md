# Mathlib: partially applied relations in recursion analysis

The Lean 4.29 reference fails at `Std.ExtDTreeMap` with
`Invalid_argument("Array.sub")`. Its field contains a quotient whose relation
is the partially applied inductive `Std.DTreeMap.Equiv α β cmp`.

The importer's `has_rec_hyp` inspects container parameters to predict the
recursive hypotheses generated by Rocq. It treated this relation as a fully
applied type and sliced five parameters from an application containing three.
The missing two arguments are the map values: the partial application is valid
Lean/Rocq syntax for a binary relation.

The patch is in the live importer's `src/lean.ml`: eta-expand uniform container
parameters with `Termops.eta_expand_instantiation`, then inspect their bodies
under the lambda binders. Parameter types use the container's universe instance.
This follows the existing `Indrec.make_rec_call_hyp` / `compute_pred` path in
Rocq. No kernel, foundation, exported declaration or checking rule is changed.

The essential Lean example is:

```lean
universe u
structure Rel (α : Type u) (x y : α) : Prop where
  property : True
structure Trigger (α : Type u) where
  inner : Quot (Rel α)
```

`Minimal.lean` adds dependent/function-valued container parameters and a
projection computation proof. `minimal-focused-baseline/Full.run.log` reproduces
the original exception on `Trigger`; `minimal-fixed/Full.run.log` passes all
17 entries. `baseline-original-timeout/Full.run.log` reproduces the same exception
on the actual `Std.ExtDTreeMap`, after checking its 422,608-line dependency export.
The first diagnostic, `baseline/`, used a shorter timeout and stopped earlier;
it is not the before/after comparison. `minimal-baseline/` was cancelled during
an unnecessarily broad export and is not a checking result. Its two temporary
export files were removed (386 MiB); the source, logs and exit status are retained.

`fixed/Full.run.log` now checks all 2,494 entries of the original dependency
export and produces `Full.vo`. Its export and kernel hashes match the failing
baseline; only the importer plugin changed. `regressions-fixed/passed.json`
records 14 passing existing importer fixtures, including mutual/nested
recursors, dependent projections, SProp and universe instances. The runner's
27 orchestration tests also pass. No full Mathlib or cslib rerun is claimed.
